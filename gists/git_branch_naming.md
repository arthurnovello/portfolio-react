### `<tipo>/<nome>`

#### `<tipo>`
```
bug    - Mudanças no codigo ligadas a um problema conhecido.
feat   - Nova função.
hotfix - Correções no codigo.
junk   - Experimentos (nunca subirão pra *master*).
```

#### `<nome>`
Sempre use traços para separar as palavras, e mantenha os nomes curtos.

#### Exemplos
```
feat/renderer-cookies
hotfix/dockerfile-base-image
bug/login-ie
```
